# MIT Applied AI & Data Science Projects

Selected projects completed during the **Applied Data Science Program: Leveraging AI for Effective Decision-Making** offered by MIT Professional Education.

This repository brings together practical machine learning and deep learning projects across healthcare, recommendation systems, forecasting, audio classification, and customer analytics. Each folder contains the original analysis notebook with its saved outputs.

## Projects

| Area | Project | Main methods |
|---|---|---|
| Healthcare | Chest X-ray classification | Transfer learning, CNNs, Grad-CAM |
| Healthcare | Chronic kidney disease prediction | Classification, feature selection, PCA |
| Healthcare | Hospital stay duration prediction | Regression, ensemble models, feature importance |
| Recommendation systems | Amazon electronics recommender | Collaborative filtering, SVD, neural collaborative filtering |
| Forecasting | Crude oil production forecasting | ARIMA, Auto-ARIMA, LSTM |
| Audio | Spoken-digit recognition | MFCCs, ANN, CNN |
| Customer analytics | Credit-card customer segmentation | PCA, t-SNE, clustering |
| Customer analytics | Potential customer prediction | Classification, model comparison, SHAP |

## Notes

- The notebooks retain their outputs so the analyses can be reviewed without rerunning every model.
- Original datasets are not redistributed. Dataset references and loading instructions are included where available in the notebooks.
- These are educational projects and are not intended for clinical or operational deployment.
